# AI-помощник продакт-менеджеров и обучение команды

**Создал AI-агента с базой знаний для продакт-менеджеров и обучал команду работе с ChatGPT и анализу рынка с помощью ИИ.**

[← Все кейсы](../README.md)

## Контекст

Работал продакт-менеджером в digital-агентстве: координировал команду из 30+ человек и 7–12 проектов в месяц. На этом фоне занимался внедрением ИИ в повседневную работу сотрудников.

Управлял рекламными бюджетами до 10 млн ₽ в месяц; команда привлекала более 100 тыс. лидов в месяц. Эти показатели описывают масштаб работы агентства в тот период.

Задача включала два направления: внутренний инструмент с рабочими знаниями и обучение людей, которые будут пользоваться ИИ.

## Мой вклад

- Создал AI-агента с базой знаний для продакт-менеджеров.
- Обучал команду работе с ChatGPT.
- Обучал анализу рынка с помощью ИИ.

## Из чего состоит решение

| Направление | Что реализовано |
| --- | --- |
| Внутренний AI-помощник | Агент с базой знаний под задачи продакт-менеджеров |
| Освоение инструментов | Обучение команды работе с ChatGPT |
| Прикладной сценарий | Анализ рынка с использованием ИИ |

База знаний даёт помощнику рабочие материалы для предметной задачи. Обучение команды дополняет инструмент: сотрудники осваивают его применение в своей работе.

## Результат

Подготовлен внутренний AI-помощник и проведено обучение команды. Этот опыт объединяет разработку прикладного инструмента и внедрение ИИ через работу с сотрудниками.

**Период:** работа в агентстве, июнь 2021 — июль 2024. AI-направлением занимаюсь с 2023 года.

**Подтверждённые инструменты и подходы:** ChatGPT, AI-агент, база знаний, обучение команды, AI-анализ рынка.
